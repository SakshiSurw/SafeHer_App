# SafeHer - Installation & Deployment Guide\n\n## 📋 Prerequisites\n\n- Node.js v16 or higher\n- npm or yarn\n- MongoDB (Local or MongoDB Atlas)\n- Git\n\n## 🔧 Local Setup\n\n### Step 1: Clone Repository\n\n```bash\ngit clone https://github.com/SakshiSurw/SafeHer_App.git\ncd SafeHer_App\n```\n\n### Step 2: Install Dependencies\n\n```bash\n# Install all dependencies (root, server, client)\nnpm run install-all\n```\n\n### Step 3: Configure Environment Variables\n\n**Server (.env)**\n```bash\ncp server/.env.example server/.env\n```\n\nEdit `server/.env` and update:\n```env\nPORT=5000\nMONGODB_URI=mongodb://localhost:27017/safeher\nJWT_SECRET=your_super_secret_jwt_key_123456789\nNODE_ENV=development\nCLIENT_URL=http://localhost:3000\n```\n\n**Client (.env)**\n```bash\ncp client/.env.example client/.env\n```\n\nEdit `client/.env`:\n```env\nREACT_APP_API_URL=http://localhost:5000\nREACT_APP_ENVIRONMENT=development\n```\n\n### Step 4: Start MongoDB\n\n**Option A: Local MongoDB**\n```bash\nmongod\n```\n\n**Option B: MongoDB Atlas (Cloud)**\n1. Create account at mongodb.com/cloud/atlas\n2. Create a cluster\n3. Get connection string\n4. Update MONGODB_URI in server/.env\n\n### Step 5: Run Development Server\n\n```bash\n# Terminal 1: Run both frontend and backend concurrently\nnpm run dev\n\n# Or run separately in different terminals:\n# Terminal 1:\nnpm run server\n\n# Terminal 2:\nnpm run client\n```\n\n**Access:**\n- Frontend: http://localhost:3000\n- Backend API: http://localhost:5000\n- API Health: http://localhost:5000/api/health\n\n## 📱 Test Credentials\n\n```\nEmail: demo@safeher.app\nPassword: demo123\n```\n\n## 🚀 Deployment\n\n### Deploy Frontend (Vercel)\n\n1. Install Vercel CLI\n```bash\nnpm install -g vercel\n```\n\n2. Deploy\n```bash\ncd client\nvercel\n```\n\n### Deploy Backend (Heroku)\n\n1. Install Heroku CLI\n```bash\nbrew tap heroku/brew && brew install heroku\n```\n\n2. Login\n```bash\nheroku login\n```\n\n3. Create app\n```bash\ncd server\nheroku create safeher-app\n```\n\n4. Set environment variables\n```bash\nheroku config:set MONGODB_URI=your_mongodb_uri\nheroku config:set JWT_SECRET=your_jwt_secret\nheroku config:set CLIENT_URL=your_vercel_frontend_url\n```\n\n5. Deploy\n```bash\ngit push heroku main\n```\n\n### Deploy with Docker\n\n1. Build images\n```bash\ndocker build -t safeher-server ./server\ndocker build -t safeher-client ./client\n```\n\n2. Run containers\n```bash\ndocker run -p 5000:5000 safeher-server\ndocker run -p 3000:3000 safeher-client\n```\n\n## 🔑 API Endpoints\n\n### Authentication\n- `POST /api/auth/register` - Register new user\n- `POST /api/auth/login` - User login\n- `GET /api/auth/profile` - Get user profile\n\n### SOS\n- `POST /api/sos/trigger` - Trigger SOS alert\n- `POST /api/sos/cancel/:id` - Cancel SOS\n- `GET /api/sos/history` - Get SOS history\n\n### Danger Zones\n- `GET /api/danger-zones` - Get all danger zones\n- `GET /api/danger-zones/nearby` - Get nearby dangers\n- `POST /api/danger-zones/report` - Report danger zone\n\n### Safe Havens\n- `GET /api/safe-havens` - Get all safe havens\n- `GET /api/safe-havens/nearby` - Get nearby safe havens\n\n### Routes\n- `POST /api/routes/calculate` - Calculate safe route\n- `GET /api/routes/history` - Get route history\n\n### Contacts\n- `GET /api/contacts` - Get all contacts\n- `POST /api/contacts` - Add contact\n- `PUT /api/contacts/:id` - Update contact\n- `DELETE /api/contacts/:id` - Delete contact\n\n## 🐛 Troubleshooting\n\n### Port Already in Use\n```bash\n# Kill process on port 5000\nlsof -ti:5000 | xargs kill -9\n\n# Kill process on port 3000\nlsof -ti:3000 | xargs kill -9\n```\n\n### MongoDB Connection Error\n- Ensure MongoDB is running\n- Check MONGODB_URI in .env\n- Verify network access (for Atlas)\n\n### CORS Errors\n- Update CLIENT_URL in server/.env\n- Restart server\n\n### Dependencies Issues\n```bash\n# Clear npm cache\nnpm cache clean --force\n\n# Remove node_modules and reinstall\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n## 📚 Project Structure\n\n```\nSafeHer_App/\n├── server/\n│   ├── models/           # MongoDB schemas\n│   ├── routes/           # API endpoints\n│   ├── middleware/       # Auth middleware\n│   ├── config/           # Database config\n│   ├── server.js         # Express server\n│   ├── package.json\n│   └── .env.example\n├── client/\n│   ├── src/\n│   │   ├── components/   # React components\n│   │   ├── pages/        # Page components\n│   │   ├── store/        # Redux store\n│   │   ├── services/     # API services\n│   │   ├── App.js\n│   │   └── index.js\n│   ├── public/\n│   ├── package.json\n│   └── .env.example\n├── package.json          # Root package\n├── README.md\n└── .gitignore\n```\n\n## 🤝 Contributing\n\n1.
